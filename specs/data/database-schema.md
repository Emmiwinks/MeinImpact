# Database Schema

## Purpose
Defines all PostgreSQL tables, their fields, constraints, indexes, and
retention rules. This is the authoritative source for the backend data model.

---

## Decisions

- **No user identity in any table.** No email, name, IP address, or
  device fingerprint is stored. See `architecture/dsgvo.md`.

- **All tables use UUID primary keys.** Generated by `gen_random_uuid()`.

- **JSONB for flexible structured fields.** `werte_relevanz` and
  `action_types` use JSONB/array types to avoid schema migrations for
  classification result changes.

- **No ORM magic for schema definition.** Alembic migration files are
  the authoritative schema. SQLAlchemy models reflect the schema but
  do not drive it.

- **Soft delete via `active` flag on actions.** Hard delete is reserved
  for GDPR erasure requests (which currently affect no stored personal
  data) and manual curation.

## Tables

### `actions`

The public civic action pool. Populated by the ingestion pipeline.
Read by all devices. Contains no user data.

```sql
CREATE TABLE civic_actions (
    id                  UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    title               TEXT NOT NULL,
    action_type         TEXT NOT NULL,
        -- 'representative_letter' | 'petition_signature' | 'public_question'
    summary             TEXT NOT NULL,
    urgency             TEXT NOT NULL DEFAULT 'low',
        -- 'high' | 'mid' | 'low'
    deadline            DATE,
        -- NULL = ongoing / no fixed deadline
    source_url          TEXT NOT NULL UNIQUE,
    external_id         TEXT,
        -- ID in the originating source system (DIP, WeAct, etc.)
    effort_minutes      INTEGER NOT NULL DEFAULT 15,
    impact_hint         TEXT NOT NULL DEFAULT '',
    pro_argumente       TEXT[] NOT NULL DEFAULT '{}',
    contra_argumente    TEXT[] NOT NULL DEFAULT '{}',
    werte_relevanz      JSONB NOT NULL DEFAULT '{}',
        -- {"wirtschaft": 0.8, "diplomatie": 0.0, "freiheit": -0.5, "wandel": 0.6}
    action_types        TEXT[] NOT NULL DEFAULT '{}',
        -- Which action types are applicable: 'brief' | 'petition' | 'anfrage'
    is_controversial    BOOLEAN NOT NULL DEFAULT false,
    position_required   BOOLEAN NOT NULL DEFAULT false,
    tavily_context      TEXT,
        -- Cached web context, used for letter generation
        -- NOT sent to device in pool download
    momentum_score      FLOAT NOT NULL DEFAULT 0.3,
        -- 0.0–1.0, derived from beratungsstand imminence + petition velocity
    active              BOOLEAN NOT NULL DEFAULT true,
    created_at          TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at          TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE INDEX idx_actions_active ON civic_actions (active);
CREATE INDEX idx_actions_urgency ON civic_actions (urgency) WHERE active = true;
CREATE INDEX idx_actions_deadline ON civic_actions (deadline) WHERE active = true;
CREATE INDEX idx_actions_created ON civic_actions (created_at DESC);
```

**Retention:** Actions are deactivated (not deleted) 7 days after deadline.
Hard delete after 90 days inactive, via scheduled cleanup job.

**Note:** `tavily_context` is stored server-side for letter generation
but is NOT included in the pool download response to devices. Devices
fetch it implicitly when requesting action context (Flow 3).

### `beta_tokens`

MVP access control. No identity attached.

```sql
CREATE TABLE beta_tokens (
    token           UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    used            BOOLEAN NOT NULL DEFAULT false,
    activated_at    TIMESTAMPTZ,
        -- Set when first activated. No identity, just timestamp.
    created_at      TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE INDEX idx_beta_tokens_used ON beta_tokens (used);
```

**Retention:** Deleted in bulk when beta phase ends and production
auth is introduced.

### `push_subscriptions`

Anonymous push notification subscriptions.

```sql
CREATE TABLE push_subscriptions (
    push_token      TEXT PRIMARY KEY,
        -- Device-issued token from FCM or APNS
    action_ids      UUID[] NOT NULL DEFAULT '{}',
        -- Actions this device wants to be notified about
    platform        TEXT NOT NULL,
        -- 'fcm' | 'apns'
    created_at      TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at      TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE INDEX idx_push_action_ids ON push_subscriptions USING GIN (action_ids);
```

**Retention:** Deleted when push token becomes invalid (FCM/APNS
delivery failure with InvalidRegistration error). Deleted on user
opt-out. Deleted if not updated in 180 days.

### `action_stats`

Anonymous completion counters. No user linkage.

```sql
CREATE TABLE action_stats (
    action_id           UUID PRIMARY KEY REFERENCES actions(id),
    completion_count    INTEGER NOT NULL DEFAULT 0,
    updated_at          TIMESTAMPTZ NOT NULL DEFAULT now()
);
```

**Retention:** Retained indefinitely as civic impact data.

### `tracking_events`

Civic outcomes for tracked actions. All public data, no user reference.

```sql
CREATE TABLE tracking_events (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    action_id       UUID NOT NULL REFERENCES actions(id),
    event_type      TEXT NOT NULL,
        -- 'vote_result' | 'petition_milestone' | 'petition_submitted'
        -- | 'mdb_response' | 'law_passed' | 'law_rejected'
        -- | 'consultation_closed' | 'custom'
    title           TEXT NOT NULL,
        -- Short headline for notification: "Abstimmung: Ja-Mehrheit"
    description     TEXT NOT NULL,
        -- Full description shown in tracking detail
    outcome         TEXT,
        -- 'positive' | 'negative' | 'neutral' | null
        -- Relative to action's pro_argumente direction
    source_url      TEXT,
    occurred_at     TIMESTAMPTZ NOT NULL,
    created_at      TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE INDEX idx_tracking_action ON tracking_events (action_id);
CREATE INDEX idx_tracking_occurred ON tracking_events (occurred_at DESC);
```

**Retention:** Retained indefinitely as civic record.

### `feedback`

Anonymous in-app feedback on action quality and AI output.

```sql
CREATE TABLE feedback (
    id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    action_id   UUID REFERENCES actions(id),
        -- NULL if feedback is about the app generally
    rating      SMALLINT CHECK (rating BETWEEN 1 AND 5),
    comment     TEXT,
        -- Max 500 chars, enforced at API layer
    created_at  TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE INDEX idx_feedback_action ON feedback (action_id);
CREATE INDEX idx_feedback_created ON feedback (created_at DESC);
```

**Retention:** 12 months, then deleted.

### `api_spend`

Operational cost tracking. No user data.

```sql
CREATE TABLE api_spend (
    id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    date        DATE NOT NULL,
    provider    TEXT NOT NULL,
        -- 'mistral' | 'tavily' | 'newsdata'
    endpoint    TEXT,
        -- 'classify' | 'context' | 'letter' | 'search' | 'news'
    tokens_used INTEGER,
    cost_eur    NUMERIC(10, 6) NOT NULL,
    created_at  TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE INDEX idx_api_spend_date ON api_spend (date DESC);
CREATE INDEX idx_api_spend_provider ON api_spend (provider, date);
```

**Retention:** 24 months.

### `mdb_statements`

Cached MdB public statement search results. Used for tracking.
Refreshed daily per active action. Stores both found and not-found results.

```sql
CREATE TABLE mdb_statements (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    action_id       UUID NOT NULL REFERENCES actions(id),
    mdb_name        TEXT NOT NULL,
    mdb_aw_id       INTEGER,
        -- Abgeordnetenwatch politician ID
    found           BOOLEAN NOT NULL,
        -- false = no statement found in last 30 days
    statement_summary TEXT,
        -- AI-summarised statement, NULL if found=false
    source_url      TEXT,
    searched_at     TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE INDEX idx_mdb_statements_action ON mdb_statements (action_id);
CREATE INDEX idx_mdb_statements_searched ON mdb_statements (searched_at DESC);
CREATE UNIQUE INDEX idx_mdb_statements_action_mdb
    ON mdb_statements (action_id, mdb_name);
```

**Retention:** Overwritten on each daily refresh (upsert on action_id + mdb_name).
Deleted when parent action is deleted.

### `pipeline_runs`

Ingestion pipeline execution log. Operational only.

```sql
CREATE TABLE pipeline_runs (
    id                  UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    fetched_count       INTEGER NOT NULL DEFAULT 0,
    deduplicated_count  INTEGER NOT NULL DEFAULT 0,
    prefiltered_count   INTEGER NOT NULL DEFAULT 0,
    classified_count    INTEGER NOT NULL DEFAULT 0,
    inserted_count      INTEGER NOT NULL DEFAULT 0,
    errors              TEXT[] NOT NULL DEFAULT '{}',
    duration_seconds    FLOAT,
    ai_cost_eur         NUMERIC(10, 6),
    ran_at              TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE INDEX idx_pipeline_ran_at ON pipeline_runs (ran_at DESC);
```

**Retention:** 90 days.

## Pool Download View

The device pool download endpoint serves a subset of `actions` fields.
`tavily_context` is excluded from the pool download to keep payload small.

```sql
CREATE VIEW actions_pool AS
SELECT
    id, title, action_type, summary, urgency, deadline,
    source_url, effort_minutes, impact_hint,
    pro_argumente, contra_argumente,
    werte_relevanz, action_types, is_controversial,
    position_required, momentum_score, created_at
FROM civic_actions
WHERE active = true
ORDER BY
    CASE urgency WHEN 'high' THEN 1 WHEN 'mid' THEN 2 ELSE 3 END,
    momentum_score DESC,
    deadline ASC NULLS LAST
LIMIT 100;
```

## Alembic Migration Convention

- One migration file per schema change
- Migration files are named: `{timestamp}_{short_description}.py`
- Downgrade path must be implemented for every migration
- Migrations are applied automatically on backend startup in development;
  manually in production before deployment
