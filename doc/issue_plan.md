# Issue Plan

The first development phase should be tracked through GitHub issues. The issues
created from this scaffold cover security, persistence, recommendations,
streaming AI drafts, app UI, CI, and future source integrations.

## Phase 1

- Harden anonymous authentication and token lifecycle.
- Add PostgreSQL migrations and persistent repositories.
- Implement onboarding and political value profile storage.
- Implement transparent weekly action recommendation scoring.
- Implement SSE AI draft streaming through Mistral.
- Implement local encrypted identity placeholders for generated letters and
  emails.
- Build the initial Flutter onboarding and action feed.
- Add secure token storage and API client retries.
- Add action tracking and notification foundations.
- Add real civic and news source adapters.
- Complete release packaging and security hardening.
